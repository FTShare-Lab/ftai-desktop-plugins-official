# Figma 设计系统技能

本技能指导 AI 智能体通过 Figma MCP 接口解析设计稿。

## 适用场景
1. 给定 Figma File Key 或 Node ID，提取设计图层结构、AutoLayout 参数与排版样式。
2. 提取项目 Color Variables、Typography 与 Shadow 等设计系统 Token。
3. 将 Figma 组件精准还原为 Vue 3 / React + Tailwind CSS 代码。
