# Code Review 代码审查技能

本技能指导 AI 智能体执行系统化、严苛而务实的代码审查。

## 核心审查维度
1. **逻辑与正确性**：检查分支覆盖、边界条件、空指针/None 处理与生命周期异常。
2. **并发与异步**：检查死锁、竞态条件、连接泄漏、未等待的异步任务。
3. **架构与契约**：检查 API 兼容性、类型契约、模块间耦合与命名一致性。
4. **性能与资源**：检查多余的循环/内存拷贝、大批量 I/O 与 N+1 查询。
5. **可维护性**：检查是否补充了必要的中文业务注释，说明“为什么”而非复述“做了什么”。
