# Linear 项目协同技能

本技能指导 AI 智能体通过 Linear 官方 MCP 接口管理研发任务。

## 适用场景
1. 搜索分配给当前用户的 Issue、待办与 Bug 清单。
2. 根据产品需求自动创建格式规范的 Linear Issue 并设置优先级。
3. 更新任务状态（In Progress, In Review, Done）。
4. 检索团队 Project 与 Cycle 迭代规划。
