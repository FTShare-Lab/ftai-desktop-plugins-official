# GitLab 协同与 CI/CD 技能

本技能指导 AI 智能体通过 GitLab MCP 服务与 GitLab 实例交互。

## 适用场景
1. 查看和创建 GitLab Merge Request (MR)，分析 MR Diff 与审查意见。
2. 检索 GitLab Issue 与项目需求。
3. 查看 CI/CD Pipeline 状态、Job 失败日志并诊断构建错误。
4. 浏览自建 GitLab (如企业内部 Git) 或 GitLab.com 上的项目文件。
