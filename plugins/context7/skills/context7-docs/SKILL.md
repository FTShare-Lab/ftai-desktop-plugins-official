# Context7 技术文档技能

本技能指导 AI 智能体通过 Context7 检索最新开发文档。

## 适用场景
1. 查询主流开源库（如 Tailwind v4, React 19, Vue 3.5, Next 15, Prisma, Tauri v2 等）的官方文档与 Breaking Changes。
2. 获取 SDK、API 规范与最新代码范例。
3. 诊断特定库的集成错误与配置迁移问题。
