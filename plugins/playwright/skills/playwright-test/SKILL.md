# Playwright 浏览器自动化技能

本技能指导 AI 智能体通过 Playwright MCP 工具控制浏览器并执行端到端验证。

## 适用场景
1. 打开本地开发服务器或远程网站（如 `http://localhost:5173`）。
2. 点击按钮、填写输入框、滚动页面与模拟各种用户手势交互。
3. 截图页面或组件并检查视觉渲染与布局对齐情况。
4. 捕获浏览器控制台日志（Console Error/Warn）与网络请求状态。
